# Security Policy

Report a suspected security vulnerability privately, through a [private vulnerability report](https://github.com/amirhs1/PolyPhys/security/advisories/new). **Do not file a public issue.** In your report, include:

- A clear description of the vulnerability and its potential impact
- Steps to reproduce the issue, including code snippets or test cases if applicable

Reporting privately allows time to investigate and fix the problem before the details are public, which reduces the risk of malicious exploitation.

This project is maintained by a single developer on a reasonable-effort basis. Please allow up to **90 days** to address the issue before disclosing it publicly.
